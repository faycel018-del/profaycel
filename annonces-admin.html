TYPES D'ANNONCES

Catégories possibles

Les annonces pourront être classées selon leur objectif.

  • Information générale
  • Nouveau cours
  • Devoir
  • Évaluation
  • Modification du planning
  • Absence ou changement de séance
  • Événement
  • Information importante
DESTINATAIRES

Qui peut recevoir une annonce ?

L'administration pourra choisir les destinataires de chaque publication.

  • Tous les élèves
  • Tous les parents
  • Élèves d'une classe
  • Parents d'une classe
  • Un élève spécifique
  • Un parent spécifique
STRUCTURE

Informations prévues

Chaque annonce pourra contenir :

  • Titre
  • Contenu
  • Type d'annonce
  • Destinataires
  • Classe concernée
  • Date de publication
  • Date d'expiration
  • Pièce jointe
  • Statut : brouillon / publié
