# 🎨 البراند
- `brand.json` — الألوان، خط السبتيتل، اللهجة، الـgrade الافتراضي. **بدّلهم بمتاعك.**
- `fonts/` — حط خطوط .ttf (ننصح **Cairo ExtraBold** ولا **Tajawal ExtraBold** من Google Fonts للعربي، **Montserrat Black** للاتيني). مبعد بدّل `subtitles.font` في brand.json لاسم الخط.
- `logo/` — لوغو PNG شفاف (يتحط وحدو على الـthumbnails).
- `luts/` — ملفات .cube للـcolor grading (`grade.sh in out brand/luts/x.cube`).
- `music/` — موسيقى royalty-free (YouTube Audio Library, Pixabay Music, Uppbeat).
