# Ideas and script

1. Read `brand/brand.json` (tone, language) and `docs/viral-playbook.md`.
2. If the topic is missing, ask: the topic, the audience, the primary platform, and the goal.
3. **Ideas**: give 10 ideas by default, each with:
   - a format (list / storytime / before-after / myth-vs-fact / tutorial / POV …)
   - **3 alternative hooks** in Tunisian dialect (under 10 words, works without sound)
   - a suggested length and platform
   - a virality score out of 10, with one line explaining why
4. Once the user picks one, write a **full script** in the `templates/script.md` table:
   time · picture (shot type: close/medium/B-roll) · speech · on-screen text · sound effect.
   Add: a **shot list** for the shoot, a caption, 3–5 hashtags, and a CTA.
5. Save it: new ideas go in `ideas/ideas.md`. If there is a project, the script goes in `projects/<p>/script.md`.
6. If the user wants trends, use WebSearch to look up what is working now (sounds, formats) in Tunisia and the region.

The style: dialect close to the audience, short sentences, a pattern interrupt every 3–5 seconds, and an open loop before the middle.
