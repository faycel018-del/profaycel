# 🔥 دليل المحتوى الجذاب (Hooks · Retention · Formats)

## 1) الـHook — أول 1–2 ثواني تقرر كل شي
**الصيغ اللي تخدم:**
1. **التحذير:** "ما تشريش X قبل ما تشوف هذا"
2. **النتيجة أولاً:** تبدا بالنتيجة النهائية، ومبعد "هكا عملتها"
3. **الرقم:** "3 حاجات تونسي لازم يعرفهم على…"
4. **السؤال الشخصي:** "علاش ديما…؟"
5. **عكس الشائع:** "الكل يقولك X… غالط"
6. **الفضول المفتوح:** "اللي صار في الآخر ما كنتش نستنا فيه"
7. **POV / تمثيل:** "POV: أمك تشوفك تخرج في 11 الليل"
8. **التحدي/التجربة:** "جربت نعيش بـ10 دينار نهار كامل"

**قواعد الصورة في الـHook:** حركة من أول فريم · نص كبير على الشاشة · وجه قريب ولا حاجة غريبة · بلاش لوغو/intro.

## 2) الـRetention (الناس تكمل الفيديو)
- قص كل سكات (`cut_silence.py`) — ولا نفس زايد.
- **Pattern interrupt** كل 3–5 ثواني: زوم، تبديل زاوية، B-roll، صوت effect، نص.
- **Open loop:** "والنقطة الثالثة هي الأهم…" — خلي سبب للتكملة.
- سبتيتل ديما (85% يتفرجو بلا صوت في فيسبوك).
- **Loop ending:** آخر جملة تتربط بأول جملة → الناس تعاود (TikTok يحب هذا).

## 3) Formats مجربة
| Format | المنصة | المدة |
|--------|--------|------|
| Talking head + B-roll + سبتيتل | الكل | 30–60s |
| Before / After | Reels, TikTok | 7–15s |
| List "3 حاجات…" | الكل | 30–45s |
| Storytime | TikTok, YouTube | 45s–3m |
| Tutorial خطوة بخطوة | Shorts, YouTube | 30s–10m |
| Day in the life / Vlog | Reels, YouTube | 30s–15m |
| Reaction / Duet / Stitch | TikTok | 15–45s |
| Myth vs Fact | الكل | 20–40s |
| Behind the scenes | Instagram, Facebook | 15–30s |

## 4) فرق بين المنصات
- **TikTok:** خام، سريع، trends، أصوات trending. أحسن أوقات (تونس): 12h–14h و 19h–22h.
- **Instagram Reels:** جمالية أعلى، grade نظيف، كابشن قصير، 3–5 هاشتاغ.
- **YouTube Shorts:** عنوان واضح فيه كلمة مفتاح، يخدم على البحث. 
- **YouTube طويل:** Thumbnail + عنوان = 80% من النجاح. فصول (chapters). أول 30 ثانية = وعد الفيديو.
- **Facebook:** جمهور أكبر سنًا، قصص ومشاعر وفكاهة محلية. السبتيتل إجباري. 1:1 ولا 4:5 للفيد.

## 5) سيستم النشر
- **فيديو واحد → 5 منصات:** صور عمودي 9:16 بإطار واسع، `export.sh all` يطلع الكل.
- **ريتم:** 3–5 shorts في الجمعة + 1 طويل (كان YouTube).
- **Batch:** نهار للأفكار + سكريبت · نهار تصوير 4–6 فيديوهات · نهار مونتاج.
- كل أحد: شوف الأرقام (retention، shares، saves) وعاود الـformat اللي خدم.

## 6) Checklist قبل النشر
- [ ] الـHook يخدم بلا صوت؟
- [ ] السبتيتل صحيح وما يتغطاش بأزرار المنصة (safe zone)؟
- [ ] الصوت -14 LUFS، الموسيقى ما تغطيش الكلام؟
- [ ] Thumbnail/Cover واضح في حجم صغير؟
- [ ] كابشن + CTA + هاشتاغات؟
- [ ] حقوق الموسيقى (استعمل مكتبة المنصة ولا موسيقى royalty-free)؟
